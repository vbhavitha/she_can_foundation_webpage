# She Can Foundation Website

A simple and responsive NGO website created for the She Can Foundation Web Development Internship Task.

## 🌟 Project Overview

This project is designed to spread awareness about women empowerment and community support through a clean and modern website interface.

The website includes:
- Home Section
- About Section
- Volunteer / Join Us Button
- Responsive Design
- Modern UI
- Footer Section

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript

## ✨ Features

- Responsive layout for mobile and desktop
- Smooth navigation
- Modern and clean design
- Interactive buttons
- Separate About page
- Hover animations and effects

## 📂 Project Structure

she-can-foundation/

## 🚀 How To Run The Project

1. Download or clone the repository

```bash
git clone [https://github.com/vbhavitha/she_can_foundation_webpage]
```

2. Open the project folder in VS Code

3. Open `index.html` using Live Server
